## 🧪 Experiência prática com testes

Tenho praticado QA com foco em situações reais, analisando não apenas se uma funcionalidade funciona, mas também se ela respeita as regras do sistema.

Exemplos de validações realizadas:

- Usuário sem permissão tentando acessar recurso restrito
- API aceitando dados inválidos
- Pedido sendo criado com produto inexistente
- Fluxo retornando status code incorreto
- Dados sendo salvos de forma diferente do esperado
- Regras de negócio não aplicadas corretamente
- Validação de mensagens de erro
- Conferência entre resposta da API e dados persistidos
